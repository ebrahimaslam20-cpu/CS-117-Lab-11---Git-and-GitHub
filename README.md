# Storage Estimator

## Purpose

This program estimates the total storage used by a group of files.

## How to Run

Open PowerShell in the project folder and type:

```bash
python storage_estimator.py
```

## Example Input

Number of files: 10

Average size of each file in MB: 5

## Example Output

Total storage: 50.00 MB

Total storage: 51200.00 KB

Total storage: 0.0488 GB
